# Hangar & Harbor — Squarespace Setup Guide

This site was designed and built in full outside Squarespace (in the `/site` folder of this repo) so you have a complete, working reference — every page, every line of copy, the exact color palette, and a recreated logo mark. Squarespace does not allow uploading a self-contained multi-page HTML site directly (that requires their Developer Platform, a separate enrollment), so the fastest real path to getting this live on hangarharbor.com is to **rebuild it inside Squarespace's own page editor using the content and design decisions below.** This guide gives you everything needed to do that in an afternoon rather than starting from a blank page.

Open the built site (`/site/index.html` and friends) in a browser side-by-side while you work — it's your visual reference for spacing, hierarchy, and tone.

---

## 1. Before you start in Squarespace

- **Template**: Pick a Squarespace 7.1 template with a full-bleed hero and clean typographic focus — anything in their "Bergen," "Paloma," or "Ansel" family works well. 7.1 templates are all built on the same Fluid Engine, so the exact template matters less than the settings below.
- **Logo files**: Use `/site/assets/img/logo-badge-512.png` (or `-1024.png` for higher resolution needs) — upload this as your site logo and as your favicon in Design → Logo & Title.
- **Fonts**: Squarespace's font picker includes Google Fonts. Set:
  - Headings → **Playfair Display** (weight 600/700)
  - Body → **Inter** (weight 300–400)
  - (Optional accent/italic font used for taglines in the built site: **Cormorant Garamond**, italic)

## 3. Site structure & navigation

Create these pages, in this order, in your main navigation:

1. **Home**
2. **Services**
3. **About**
4. **Portfolio**
5. **Contact** (also set as your header's call-to-action button: "Request Consultation" → links to Contact)

Footer navigation: repeat the same links, plus your social icons (Instagram, TikTok) linked via Design → Social Links.

## 5. Language rules to keep enforced site-wide

These were explicit brand requirements — keep them in mind if you or anyone else edits copy later:

- **Never use the word "detailing"** anywhere on the site. Use **"refinement"** instead. This is a positioning choice — "detailing" reads as ordinary car-wash-level service; "refinement" supports the luxury/exotic-asset positioning.
- **Don't reference specific advanced techniques** like "paint correction," "paint treatment," ceramic coating, etc. until you've actually performed that kind of work for a client. Right now, automotive scope is described only as interior/exterior refinement (hand washing, interior deep-clean, trim/glass/leather care) — accurate to what the business currently does.
- **No insurance/certification claims** — none are mentioned anywhere in the copy above, intentionally, since you'll add real insurance/bonding language once it's in place.
- **No fabricated portfolio media** — the Portfolio page uses "Coming Soon" placeholders, not stock photos, so nothing on the site misrepresents work you haven't done yet.

## 6. Code Injection (optional polish)

If you want pixel-closer typography/spacing matching the built reference site, go to **Settings → Advanced → Code Injection** and add this to the **Header**:

```html
<link rel="preconnect" href="https://fonts.googleapis.com">
<link rel="preconnect" href="https://fonts.gstatic.com" crossorigin>
<link href="https://fonts.googleapis.com/css2?family=Playfair+Display:wght@500;600;700&family=Cormorant+Garamond:ital,wght@0,500;0,600;1,500&family=Inter:wght@300;400;500;600&display=swap" rel="stylesheet">
<style>
  :root{
    --hh-navy-950:#060f1e;
    --hh-navy-900:#0a1930;
    --hh-gold-500:#d4af37;
    --hh-gold-100:#f6e7b4;
    --hh-ivory:#f4efe3;
  }
  h1,h2,h3,h4 { font-family:'Playfair Display', Georgia, serif !important; }
  body, p, a, li { font-family:'Inter', sans-serif; }
</style>
```

This is optional — Squarespace's native font/color pickers (Section 1–2 above) will get you 90% of the way there without touching code at all.
